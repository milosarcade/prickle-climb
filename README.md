# Prickle Climb

A twin-stick arcade shooter. Every floor is three rooms full of
spike-spitting critters. Clear them, find the ladder and climb higher.
See how many rooms you can clear before you get squashed.

Play it: https://milosarcade.com/prickle-climb/

## Controls

| Key | Action |
|---|---|
| W A S D | Move |
| Mouse | Aim, hold to shoot |
| Arrow keys | Aim and shoot |
| Space | Dash, you can't be hit while dashing |
| Shift | Sneak slowly |
| Q | Auto-fire |
| P | Pause |
| M | Mute sound |

On a phone or tablet: left thumb moves, right thumb aims and fires, tap DASH
to dodge. Pause and mute buttons appear in the top right corner once you
touch the screen.

## How it works

- You start with 3 lives. Each floor has 3 rooms, and a door opens when a room is clear.
- After the third room a ladder appears. Climb it and pick one of three gun upgrades.
- New critters turn up on each of the first six floors.
- A boss waits in room 3 of floors 3, 6, 9 and so on. King Prickles and Madame Inkwell take turns.
- Powerups: Heart, Rapid fire, Triple shot, Shield, Slow-mo and Bomb.

R opens a floor picker for testing. Warped runs don't count toward your best.
